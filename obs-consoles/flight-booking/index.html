Estado de la infraestructura

¿Qué es la Observability Console?

La Observability Console es un dashboard de monitorización en tiempo real para toda la infraestructura del simulador de reservas de vuelos. Ofrece un único panel para el estado de los servicios, las métricas de sistema y el estado de protección de datos con Zerto.

Cómo se recogen los datos

  • Pestaña Reservas: consulta el backend (FastAPI) cada 5s vía el proxy de NGINX de esta consola.
  • Pestaña Systems: consulta los sys-probe/db-probe de cada VM a través de rutas dedicadas de NGINX.
  • Pestaña Zerto: consulta el zerto-probe local, que agrega datos de los dos ZVMA (origen y destino).
