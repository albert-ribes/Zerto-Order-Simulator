¿Qué es la Observability Console?

Dashboard de monitorización en tiempo real para toda la infraestructura del Hospital Discharge Manager. Ofrece un único panel para el estado de los servicios, las métricas de sistema y el estado de protección de datos con Zerto.

Cómo se recogen los datos

Pestaña KPIs: consulta el backend (FastAPI) cada 4s vía el proxy de nginx de esta consola.
Pestaña Systems: consulta los sys-probe/db-probe de cada VM a través de rutas dedicadas de nginx.
Pestaña Zerto: consulta el zerto-probe local (puerto 5003), que agrega datos de los dos ZVMA (origen y destino).

Arquitectura — flujo de negocio

El RBG genera altas médicas ficticias desde el Backend VM y las persiste en la BD siguiendo exactamente esta misma ruta.

Arquitectura — flujo de observabilidad

Las credenciales de Zerto solo viven en el zerto-probe, que corre en la propia VM de esta consola — nunca llegan al navegador.

Funcionalidades

  • Generación continua de altas médicas ficticias mediante el RBG (Random Booking Generator)
  • KPIs hospitalarios en tiempo real: altas procesadas, tiempo medio, camas liberadas, ocupación de planta
  • Gráficas de evolución con selector de rango temporal (15 min → 24 h)
  • Chequeo de estado y métricas de sistema (CPU, RAM, disco, uptime) de cada VM
  • Integración con Zerto ZVMA: estado de VPGs, RPO en tiempo real, alertas y eventos del journal
  • Multiidioma (ES / PT / EN) y modo oscuro / claro persistentes
